# 번역 프롬프트

한국어 원문(`posts/<slug>/index.md`)을 영어·일본어·중국어로 옮길 때 AI에게 이 파일과 [glossary.md](./glossary.md)를 함께 주고 아래 요청을 붙여 넣는다. 결과는 사람이 한 번 읽고 고친다.

```text
posts/<slug>/index.md 를 영어(index.en.md), 일본어(index.ja.md), 중국어 간체(index.zh.md)로 번역해 줘.
blog/template/translate.md 의 규칙과 blog/template/glossary.md 의 용어를 지켜.
```

## 파일

- 원문 옆에 `index.en.md`, `index.ja.md`, `index.zh.md`를 만든다. 이미 있으면 바뀐 부분만 고친다.
- frontmatter에는 `title`, `description` 두 줄만 번역해서 둔다. `date`, `tags`, `draft`는 `index.md`에만 있으므로 옮기지 않는다.
- 제목·요약에 `:` `[` `(` 같은 기호가 들어가면 큰따옴표로 감싼다.

## 본문

- 마크다운 구조를 원문과 1:1로 맞춘다. 제목 수준, 목록, 표, 문단 순서, 이미지 위치를 바꾸지 않는다.
- 줄바꿈 한 번도 화면에서 줄바꿈으로 보인다. 원문이 줄을 나눈 자리에서 똑같이 나누고, 없는 줄바꿈을 만들지 않는다.
- 코드 블록과 인라인 코드는 그대로 둔다. 코드 블록 안에서는 주석(`#`, `//`, `/* */`)만 번역하고, 문자열과 터미널 출력은 원문대로 둔다.
- 인라인 코드가 한국어 낱말을 강조하려고 감싼 것이면(`레이아웃`) 그 낱말만 번역하고 백틱은 남긴다.
- 링크 주소와 이미지 경로는 그대로 둔다. 같은 이름에 언어 코드가 붙은 이미지(`img/diagram.en.svg`)가 있으면 그 파일로 바꾼다.
- 이미지 대체 텍스트 `![여기](...)`와 캡션 `![...](... "여기")`은 번역한다.
- 콜아웃 표시 `> [!NOTE]` 와 각주 표시 `[^1]`은 그대로 둔다.
- 원문의 오타·띄어쓰기 실수는 뜻대로 자연스럽게 옮기되, 사실이나 주장은 더하거나 빼지 않는다.
- 제품·서비스·고유명사(Autodesk Tandem, GitHub, Revit, QUIPU)는 원문 표기를 그대로 쓴다.

## 말투

- 원문의 1인칭 기록체를 살린다. 원문이 `~다`로 끝나는 한다체라서 딱딱한 문서체가 아니라 개인 기술 블로그의 담담한 말투로 옮긴다.
- 영어: 짧고 쉬운 문장. 1인칭(I)을 쓰고, 설명 문장은 현재형으로 쓴다.
- 일본어: 常体(だ・である調)로 통일한다. 문장부호는 전각(、。「」), 영문·숫자와 일본어 사이는 띄지 않는다.
- 중국어: 简体中文 书面语. 문장부호는 전각(，。：；（）), 한자와 영문·숫자 사이에는 공백 하나를 둔다.

## 마친 뒤 확인

- 원문과 제목(`#`) 개수, 코드 블록 수, 이미지 수, 링크 수가 같다.
- 코드 블록은 주석을 뺀 나머지가 원문과 한 글자도 다르지 않다.
- 용어집에 없는 전문 용어를 새로 옮겼다면 결과 끝에 목록으로 알려 주고, 확정되면 glossary.md에 추가한다.
